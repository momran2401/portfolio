Radar field-of-view and positioning app

A phone-friendly web tool that replaced trial-and-error radar setup at the test site.

  • JavaScript (ES6)
  • Canvas API
  • HTML/CSS
  • Tailwind
  • Mobile
Try the tool

The problem

Setting up a radar at the test site was trial and error. Put it somewhere, aim it, check what it covers, move it, try again.

What I built

A web app that draws the radar's field-of-view cone on a canvas and recommends where to place it and how to align it. You see the coverage before you move anything.

It's a single HTML file: HTML, CSS, ES6 JavaScript, Tailwind from a CDN, and the Canvas API. Nothing to install and no build step. It's built to work on a phone, since that's what you actually have with you in the field.
